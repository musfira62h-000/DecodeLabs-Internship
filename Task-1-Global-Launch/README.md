# Task 1 — The Global Launch

A static HTML/CSS portfolio hosted on the cloud (no servers) with a public URL.

**Live site:** https://musfiraportfolio2026.z29.web.core.windows.net/

Hosted on **Azure Blob Storage** — Static website.

## Files
- `index.html` — the portfolio (CSS inlined)
- `error.html` — 404 page
- `bucket-policy.json` — AWS S3 public-read policy (only for the AWS option)
- `LIVE-LINK.md` — the live URL

## Run locally
Double-click `index.html`, or run `python -m http.server 8000` and open `http://localhost:8000`.
